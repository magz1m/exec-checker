✦ Частые вопросы ✦

Это безопасно?▾
Да. ExecChecker лишь читает список активных процессов и не вносит изменений в систему.
Нужен ли антивирус?▾
Файл .bat может вызвать подозрение у Windows Defender — это нормально для bat-скриптов.
Работает на всех версиях Windows?▾
Да, поддерживается Windows 7, 8, 10 и 11.
Как обновить программу?▾
Просто скачай файл заново по той же кнопке.
